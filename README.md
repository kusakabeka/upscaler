# 🔬 Super-Resolution App — Нейросетевое суперразрешение изображений

Приложение для увеличения разрешения изображений с помощью нейросети **ESPCN** (Efficient Sub-Pixel Convolutional Neural Network), реализованной с нуля на PyTorch.

## Структура проекта

```
super_resolution_app/
├── app.py                  # Gradio веб-интерфейс
├── train.py                # Скрипт обучения модели
├── infer.py                # CLI-инференс (одно изображение)
├── download_data.py        # Автозагрузка датасета DIV2K
├── test_pipeline.py        # Тестирование всего пайплайна
├── requirements.txt        # Зависимости
├── README.md               # Документация
│
├── models/
│   └── srcnn.py            # Архитектура ESPCN
│
├── utils/
│   ├── image_utils.py      # Загрузка/сохранение изображений
│   ├── metrics.py          # PSNR, SSIM
│   └── dataset.py          # PyTorch Dataset для обучения
│
├── checkpoints/            # Сохранённые веса моделей
├── data/                   # Данные для обучения / валидации
│   ├── train/
│   ├── val/
│   └── test/
└── outputs/                # Результаты инференса
```

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Тестирование пайплайна

```bash
python test_pipeline.py
```

Скрипт создаёт синтетические изображения и проверяет: модель, утилиты, метрики, инференс и мини-обучение.

### 3. Запуск веб-интерфейса (демо-режим)

```bash
python app.py
```

Откроется в браузере на `http://localhost:7860`. Без обученных весов модель работает с рандомными параметрами — полезно для проверки UI.

### 4. Скачивание данных для обучения

В проекте есть встроенный скрипт загрузки датасета **DIV2K** — стандартного бенчмарка для задач суперразрешения (800 HR-изображений в 2K-разрешении).

```bash
# Скачать train + val (всего ~3.7 GB)
python download_data.py

# Только тренировочный набор
python download_data.py --split train

# Только валидационный набор
python download_data.py --split val
```

Скрипт автоматически скачает архивы с официального сервера DIV2K, распакует их и разложит изображения по папкам `data/train/` и `data/val/`. ZIP-файлы после распаковки удаляются.

Если предпочитаете скачать вручную:

1. Перейдите на https://data.vision.ee.ethz.ch/cvl/DIV2K/
2. Скачайте **DIV2K_train_HR.zip** (~3.3 GB) и **DIV2K_valid_HR.zip** (~440 MB)
3. Распакуйте изображения в `data/train/` и `data/val/` соответственно

### 5. Обучение модели

```bash
# x2 (на GPU типа RTX 5090 — около 3-5 минут на 100 эпох)
python train.py --data_dir data/train --val_dir data/val \
                --scale 2 --epochs 100 --batch_size 32

# x4
python train.py --data_dir data/train --val_dir data/val \
                --scale 4 --epochs 100 --batch_size 32
```

Параметры обучения:

| Параметр       | По умолчанию | Описание                           |
|----------------|-------------|------------------------------------|
| `--scale`      | 2           | Коэффициент увеличения (2 или 4)   |
| `--epochs`     | 100         | Количество эпох                    |
| `--batch_size` | 16          | Размер батча (с GPU можно 32–64)   |
| `--patch_size` | 96          | Размер HR-патча для обучения       |
| `--lr`         | 0.001       | Learning rate                      |
| `--save_every` | 10          | Сохранять чекпойнт каждые N эпох   |

Лучшая модель по валидационному PSNR сохраняется в `checkpoints/best_x2.pth` (или `best_x4.pth`).

### Примерное время обучения (100 эпох, DIV2K, batch_size=32)

| GPU              | x2       | x4       |
|------------------|----------|----------|
| RTX 5090         | ~3–5 мин | ~4–7 мин |
| RTX 4070–4090    | ~5–15 мин| ~8–20 мин|
| RTX 3060–3080    | ~10–25 мин| ~15–30 мин|
| CPU (i7/Ryzen 7) | ~2–4 ч   | ~3–5 ч   |

### 6. Запуск с обученной моделью

```bash
python app.py --checkpoint_x2 checkpoints/best_x2.pth \
              --checkpoint_x4 checkpoints/best_x4.pth
```

### 7. CLI-инференс

```bash
python infer.py --input photo.jpg --scale 2 \
                --checkpoint checkpoints/best_x2.pth \
                --compare
```

## Архитектура модели ESPCN

Модель состоит из трёх блоков:

1. **Feature Extraction** — Conv2d(3→64, 5×5) + ReLU. Извлечение признаков из LR-изображения.
2. **Non-linear Mapping** — два слоя Conv2d(64→64→32, 3×3) + ReLU. Обучение нелинейного отображения LR→HR в пространстве признаков.
3. **Reconstruction** — Conv2d(32 → 3×scale², 3×3) + PixelShuffle(scale). Sub-pixel свёртка, которая переупорядочивает каналы в пространственные измерения.

Ключевое преимущество: вся обработка идёт в низком разрешении, апскейлинг происходит только на последнем слое — это значительно экономит вычисления.

### Количество параметров

| Масштаб | Параметры |
|---------|-----------|
| x2      | ~33 000   |
| x4      | ~69 000   |

## Метрики качества

- **PSNR** (Peak Signal-to-Noise Ratio) — чем выше, тем лучше. Типичные значения: 28–35 дБ.
- **SSIM** (Structural Similarity Index) — от 0 до 1, чем ближе к 1, тем лучше.

## Данные для обучения

### Основной датасет: DIV2K

DIV2K — стандартный бенчмарк для задач суперразрешения, используется в большинстве научных публикаций. Содержит 800 тренировочных и 100 валидационных изображений в разрешении ~2K.

Скачивается одной командой:
```bash
python download_data.py
```

### Дополнительные датасеты

| Датасет    | Изображений | Назначение                        | Источник                          |
|------------|-------------|-----------------------------------|-----------------------------------|
| DIV2K      | 800 + 100   | Обучение + валидация (основной)   | `python download_data.py`         |
| Flickr2K   | 2 650       | Дополнительные данные для обучения| github.com/limbee/NTIRE2017       |
| Set5       | 5           | Тестирование / бенчмарк           | Встроен в большинство SR-репо     |
| Set14      | 14          | Тестирование / бенчмарк           | Встроен в большинство SR-репо     |
| BSD100     | 100         | Тестирование / бенчмарк           | www.eecs.berkeley.edu/Research    |
| Urban100   | 100         | Тестирование (городские сцены)    | github.com/jbhuang0604/SelfExSR  |

Модель автоматически нарезает изображения на патчи при обучении — достаточно положить HR-картинки в папку.
